# Kiveto UI Kit Roadmap

Kiveto UI Kit built on Tailwind CSS v4 + Stimulus + Twig components.

## Existing components

- Buttons (6 variants + sizes)
- Forms (inputs, checkboxes, toggles, radios)
- Custom Select (animated, searchable, keyboard nav)
- Modals (fade+scale animation, exit animation, backdrop blur)
- Drawers (slide + backdrop blur)
- Popovers (directional fade+scale, declarative support)
- Toasts (success, danger, warning, info)
- Alerts, Banners
- Data tables
- Badges (26 color variants)
- Chips
- Cards, Widgets, Stat cards
- Tabs (pill + underline variants)
- Breadcrumbs
- Navigation (sidebar, collapsible groups)
- Layout (sidebar, topbar, rpanel, app shell)
- Spinner, Skeleton loader
- Empty state
- Avatar (4 sizes)
- Color dot
- FAB (mobile)
